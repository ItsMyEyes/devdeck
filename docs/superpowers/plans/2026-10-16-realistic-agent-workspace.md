# DevDeck realistic agent workspace

Approved plan: implement the full six-phase roadmap from the conversation on 2026-10-16.

## Constraints
Operational truth first; stylized procedural assets; garden and city; automatic device-local daylight; deterministic cosmetics; no new endpoint/database migration/provider protocol. Existing chat, archive, runtime ownership and accessibility remain intact. 20 parents + 20 children globally, selected/failed/running priority. Baseline b84d8bb.

## Tasks
1. Truthful work projection and mirrored DTOs. Idempotent item/turn/actor identity, provider-specific execution coverage, deep clone/replay, authoritative resets, generic fallback.
2. Actor admission, motion and surface contact. Global child budget including selected parent; distance-driven gait, smooth speed/yaw, stand/sit and hand/foot anchors, deterministic cosmetics.
3. Environment, material profiles and adaptive quality. Garden/city per-workspace preference, device-local four-period lighting, procedural instancing, shared materials, Auto/High/Balanced/Low and visibility/reduced-motion.
4. Real collaboration and camera. Observed delegation/result transitions, six-second completion marker without initial replay, task board, overview/desk/lounge presets, opt-in follow cancelled by manual navigation/view/removal.
5. Integrated validation and documentation. Full-app isolated fixture, lifecycle reproduction, two environments/four periods/two themes/three views, 87-test baseline and new tests, frontend typecheck/build/full suite, backend tests/vet, controlled 20+20 performance and hide tests, final independent review.

## Performance acceptance
M3/8GB, 1400x900; warmup 5s then three 30s runs per working/idle/mixed scenario; each 5s foreground window >=30fps including close zoom/interaction. No claims on unmeasured hardware.
