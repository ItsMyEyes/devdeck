DevDeck is a dashboard for running coding agents (like Claude Code or Codex)
across several client codebases at once, without juggling terminal windows
or losing track of what's running where.

In plain terms: for every task, DevDeck gives you an isolated copy of your
project's code (called a **worktree**) and a real, live terminal to run an
agent in — side by side with a file editor and a git panel, all in one
browser tab. Open five tasks and you get five independent terminals, five
independent copies of the code, and nothing ever collides.

You can run it as a single program on your own laptop, or spread it across
several machines if you need more horsepower — see [Deployment](/docs/deployment)
once you're past the basics.

<Callout title="Coming from source?">
  This guide covers installing pre-built releases. If you're building
  DevDeck from source to contribute code, see `TUTORIAL.md` in the
  repository instead.
</Callout>
