DevDeck is a multi-project dashboard for coding agents: one operator running
many companies' worth of work from a single pane of glass. It pairs git
worktrees with real terminals, so every branch an agent (or you) touches gets
its own isolated checkout, its own live PTY, and its own tiling workspace of
terminal/editor/file-explorer/git panes.

Under the hood it's a Go backend (SQLite + WebSocket PTYs) and a React
single-page app. You can run it as a single self-contained process on one
machine, or split the "organizational data" and "execution" halves across a
hub and one or more runtime machines — see [Deployment
modes](/docs/deployment-modes).
