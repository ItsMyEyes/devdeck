Each project has an **Issues** tab: a drag-and-drop kanban board (a to-do
list split into columns, where you drag a card across as it progresses)
with four columns — To Do, In Progress, In Review, and Done.

## Working with an issue

Open an issue to:

- Edit its title, Markdown description, assignee, status, and priority —
  all inline, no separate edit screen.
- Upload attachments (images show up as thumbnails).
- Post comments and single-level replies, shown in order alongside an
  auto-recorded activity log — status/priority/assignee changes appear here
  by themselves, you never create those entries yourself.

## Agents can use it too

A coding agent working inside a worktree can file and update these issues
on its own, against that same project. That means it can track its own
progress as it works — leaving you a running log — without you having to
write tickets by hand.
