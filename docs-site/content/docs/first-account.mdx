---
title: Your first account
description: Register, and set up 2FA if it's enabled.
---

A fresh DevDeck instance has no accounts yet, so you'll land on the login
screen with nowhere to go but **Register**.

## Register

Enter an email and a password (12 characters minimum). What happens next
depends on whether the instance you're connecting to has two-factor
authentication enabled:

- **2FA disabled** — you're logged in immediately, no extra steps.
- **2FA enabled** (the default for hub/runtime builds) — you're sent to a
  **2FA setup** screen:
  1. Scan the QR code with an authenticator app (Google Authenticator,
     Authy, 1Password, …).
  2. Enter the 6-digit code it generates to confirm.
  3. Save the one-time backup codes shown on screen.

<Callout title="Save your backup codes" type="warn">
  You won't see the backup codes again after this screen. They're your only
  recovery path if you lose access to your authenticator app — without them,
  there's no self-service way to recover a locked-out account.
</Callout>

Once 2FA (if any) is set up, logging in from then on is a two-step form:
email/password, then a 6-digit code (or a backup code).

## Where you land

Either way, you land on `/` — which, with no workspace yet, shows an
onboarding screen prompting you to create one. Continue to [Workspaces and
projects](/docs/workspaces-and-projects).
