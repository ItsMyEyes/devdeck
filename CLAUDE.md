# CLAUDE.md

**Loom** — one operator, many companies. Multi-project dashboard for coding agents
(git worktrees + terminals). Go backend (SQLite + WebSocket PTY) + React 19 SPA
(Vite 8, TanStack Router, @base-ui/react, Tailwind v4, zustand, xterm.js).

Detail lives in dedicated files (read on demand — not auto-loaded):

- **Architecture / structure / feature order** → `ARCHITECTURE.md`
- **Mandatory code contracts** (API shape, errors, store interface, domain sync) → `CONTRACTS.md`
- **Commands** (run, build, typecheck) → `COMMANDS.md`
- **Multi-agent orchestration** → `ORCHESTRATION.md`
- **Go rules** → `.claude/rules/go.md` (loads on `**/*.go`)
- **Frontend rules** → `.claude/rules/frontend.md` (loads on `**/*.tsx`, `**/*.ts`)

## Tool Flow
- Search: `Grep` first, then `Glob` for file discovery; use Serena `find_symbol` / `smart_search` for symbol-level lookups.
- Edit: Use Serena `replace_content` (regex mode) as primary; fall back to `Edit` for exact string replacement.
- Verify: `npm run typecheck` (frontend), `go vet ./...` (backend), `npm run build` (full).

## Non-Negotiables
- Never edit `frontend/src/routeTree.gen.ts` — it's generated by TanStack Router plugin. (See `COMMANDS.md`.)
- Domain types in `frontend/src/store/types.ts` and `backend/internal/domain/models.go` must stay in sync. (See `CONTRACTS.md`.)
- All API responses use `{"error":"message"}` envelope; never change the error shape. (See `CONTRACTS.md`.)
- All persistence goes through `port.Store` interface; never bypass it. (See `CONTRACTS.md`.)
- Go handlers use `handleStoreErr()` for store errors; never return raw SQL errors to clients.
- Frontend imports use `@/*` alias; never relative paths into `src/`.
- `verbatimModuleSyntax` is on — use `import type` for type-only imports. (See `CONTRACTS.md`.)

## Orchestration (when spawning subagents / workflows)
Subagents inherit only a snapshot of CLAUDE.md + always-on rules; they do NOT get
the detail files, files you read, or mid-session edits. So:
- Brief each subagent explicitly — name the detail file it must read.
- Never edit these convergence files from parallel agents: `frontend/src/routeTree.gen.ts`,
  `frontend/src/store/useLoomStore.ts`, `frontend/src/store/types.ts`,
  `backend/internal/domain/models.go`, `backend/cmd/server/main.go`,
  `backend/internal/port/store.go`. Serialize them, or do them in one integration step.
- Isolate parallel file-mutating agents in git worktrees; run codegen once.
Full playbook → `ORCHESTRATION.md`.
