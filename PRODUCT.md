# Product

## Register

product

## Users

DevDeck is for one operator managing many company/client coding-agent workspaces. They move between projects, git worktrees, terminals, browser panes, SSH machines, and agent task state while staying oriented across parallel work.

## Product Purpose

DevDeck is a multi-project control room for coding agents: it keeps workspaces, worktrees, terminals, browser tiles, machines, and agent surfaces visible and actionable from one app. Success means the operator can split, switch, monitor, and recover work without losing context.

## Brand Personality

Dense, calm, precise. The interface should feel terminal-native and trustworthy, with compact hierarchy, restrained teal emphasis, and macOS-like chrome that supports fast orientation rather than spectacle.

## Anti-references

Avoid SaaS gloss: no bright marketing gradients, oversized hero styling, decorative dashboard clichés, or novelty chrome that slows an operator down. Avoid UI that looks like a generic admin template or an over-decorated AI dashboard.

## Design Principles

- Preserve orientation under parallel work: every tab, split, and pane should make ownership and focus obvious.
- Keep chrome compact but legible: dense layouts are welcome when controls remain discoverable and readable.
- Use accent color as state, not decoration: teal should signal focus, selection, or primary action.
- Match platform familiarity: macOS-like window and tab conventions should behave predictably.
- Design for interruption and recovery: closed, detached, or background work should remain understandable when the operator returns.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Preserve keyboard access for tab and pane workflows, visible focus states, and reduced-motion-safe transitions.
